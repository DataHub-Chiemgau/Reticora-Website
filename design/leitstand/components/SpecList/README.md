# SpecList

Die Kennwertliste stellt Bezeichnung und Wert gegenüber, in Mono und mit tabellarischen Ziffern.

**Sie liefern:** drei bis acht Paare. Jeder Wert trägt seine Einheit.

- Einsatz neben einem erklärenden Absatz, nie als Ersatz für ihn.
- Werte stehen rechtsbündig. Zahl und Einheit trennt ein geschütztes Leerzeichen.
- Braucht ein Wert eine Quelle, folgt ihm ein `Beleg`.
- Mehr als acht Zeilen oder mehr als zwei Spalten: `DataTable` nehmen.
