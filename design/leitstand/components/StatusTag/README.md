# StatusTag

Das Statuskennzeichen zeigt einen Zustand als Wort mit einer Lampe davor, wie die Statusanzeige der App.

**Sie liefern:** das Wort aus dem Katalog der App und die Lampenfarbe.

- Einsatz nur in Schemazeichnungen und Tabellen, die Zustände der App erklären. Nie als Schmuck neben Überschriften.
- Das Wort trägt die Bedeutung, die Lampe verstärkt sie. Grün: in Ordnung. Bernstein: braucht Aufmerksamkeit. Rot: Fehler. Grau: unbekannt.
- Wörter exakt wie in der App: „Aktiv“, „Inaktiv“, „Wartung“, „Außer Betrieb“, „Unbekannt“.
