# SiteFooter

Die Fußzeile führt jede Seite der Website in vier Spalten auf und trägt die Pflichtlinks.

**Sie liefern:** nichts von Hand. Die Spalten entstehen aus der Seitenstruktur, die Firmierung aus der zentralen Anbieter-Datei.

- „Impressum“ und „Datenschutz“ stehen auf jeder Seite, auch auf der Fehlerseite, mit genau diesen Wörtern und einem Klick erreichbar.
- Die untere Zeile nennt die Firmierung des Anbieters, die Rechtslinks, den Satz „Angebot nur für Unternehmen“ und die andere Sprache.
- Keine Social-Media-Symbole, kein Newsletter-Feld, keine Siegel.
- Spaltentitel in `data-label`, Links in `body-s` und `fg`.
