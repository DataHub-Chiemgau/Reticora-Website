# Beleg

Ein Beleg hängt an einer Aussage und nennt beim Aufklappen, worauf sie sich stützt.

**Sie liefern:** die Nummer der Aussage im Claim-Register. Titel, Inhalt und Stand kommen von dort.

- Pflicht bei jeder Aussage mit Zahl, bei jeder Aussage zu Sicherheit, Datenschutz und Datenstandort.
- Der Beleg nennt die Tatsache und den Stand, nicht das Repository. Verweise gehen auf öffentliche Dokumentation, sobald es sie gibt.
- `details`-Element: funktioniert ohne JavaScript und per Tastatur. Die Marke misst mindestens 24 px in der Höhe.
- Nie mehr als ein Beleg je Satz. Stützt sich ein ganzer Abschnitt auf dieselbe Quelle, steht der Beleg am ersten Satz.
- Ein Beleg ersetzt keine Formulierung: Was nicht belegt ist, wird gestrichen.
