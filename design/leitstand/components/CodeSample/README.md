# CodeSample

Das Code-Beispiel zeigt einen echten Aufruf der API mit Kopierknopf.

**Sie liefern:** die Kopfzeile (Methode und Pfad), den Code und die Sprache.

- Nur Aufrufe, die in der OpenAPI-Beschreibung stehen. Pfade beginnen mit `/api/v1`, der Schlüssel steht im Kopf `X-API-Key`.
- Schlüssel immer gekürzt (`rk_live_…`), nie ein vollständiger Wert.
- Drei Farben: `fg` für Code, `accent-strong` für Zeichenketten, `fg-subtle` für Kommentare. `signal` ist für Zustände reserviert und kommt im Code nicht vor.
- Lange Zeilen scrollen im Rahmen. Der Kopierknopf ist die einzige Stelle, an der das Beispiel JavaScript braucht; ohne JavaScript fehlt nur der Knopf.
