# Steps

Der Ablauf zeigt eine echte Reihenfolge als nummerierte Liste.

**Sie liefern:** drei bis sechs Schritte mit Titel und einem Satz.

- Nur für Abläufe, deren Reihenfolge feststeht: die fünf Schritte der Einrichtung, der Weg einer Beobachtung vom Collector in die CMDB.
- Titel wie in der App („Collector verbinden“, „Scopes bestätigen“).
- Die Nummern stehen in Mono und `accent`. Für Aufzählungen ohne Reihenfolge keine Nummern.
- Eine geordnete Liste (`ol`), damit Screenreader die Position ansagen.
