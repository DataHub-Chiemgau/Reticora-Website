# Logos

Die Bildmarke ist das Fadenkreuz aus der App (`frontend/src/components/shell/Brand.tsx`): Ring, vier Striche, Mittelpunkt, Strichstärke 1,75 im 24er-Raster. Sie wird nicht verändert.

- `reticora-mark-leitstand.svg`: Strich in `accent` des Leitstand-Themas (#4cc3ce), für dunkle Gründe.
- `reticora-mark-dokument.svg`: Strich in `accent` des Dokument-Themas (#087680), für helle Gründe.

Auf der Website steht die Bildmarke als Inline-SVG mit `currentColor` in `accent`, daneben das Wort „Reticora“ in `fg`, Gewicht 600. Mindestgröße 20 px. Freiraum ringsum: ein Viertel der Kantenlänge.
